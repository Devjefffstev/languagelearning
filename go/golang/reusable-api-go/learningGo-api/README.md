# Learning Go API

This is a sample API for learning Go concepts, starting from basics to senior-level topics.

## Prerequisites

- **Go**: Version 1.22 or higher. [Download Go](https://go.dev/dl/)

## Getting Started

### 1. Run the API

You can run the API directly using `go run`:

```bash
# Navigate to the service directory
cd reusable-api-go/learningGo-api

# Run the server
go run ./cmd/api/main.go
```

The server will start on port `8000`.

### 2. Run via Docker

Alternatively, you can run the API in a container:

```bash
# Build the image
docker build -t learning-go-api .

# Run the container (background, name: learning-api, port: 9000->8000)
docker run -d -p 9000:8000 --name learning-api learning-go-api

# Stop the container
docker stop learning-api

# Remove the container
docker rm learning-api
```

### 3. Test the Endpoint

You can use `curl` to test the basic example endpoint:

```bash
curl -X POST http://localhost:8000/basic
```

**Response:**
```text
Basic Go Examples
```

## API Documentation (Swagger)

This API uses Swagger for interactive documentation.

1.  **Ensure the server is running** (see step 1 above).
2.  Open your browser and visit:
    [http://localhost:8000/swagger/index.html](http://localhost:8000/swagger/index.html)

You can explore endpoints and test them directly from the UI.

## Project Structure

- `cmd/api/main.go`: Entry point. Wires up dependencies, routes, and starts the server.
- `internal/basic`: Contains basic handler examples.
- `docs/`: Autogenerated Swagger documentation files.

## Troubleshooting

### Port 8000 already in use
If you see the error `listen tcp :8000: bind: address already in use`, it means the server is already running in the background or another process is using that port.

**To resolve this:**

1. Find the process ID (PID) using port 8000:
   ```bash
   lsof -i :8000
   ```
2. Kill the process:
   ```bash
   kill -9 <PID>
   ```
